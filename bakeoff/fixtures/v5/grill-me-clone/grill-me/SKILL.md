---
name: grill-me
description: Stress-test a plan or design through relentless Socratic questioning until shared understanding. Use when the user says "grill me", wants to stress-test a plan, or review a design decision. Do NOT use for implementation or code generation.
---

Interview relentlessly about every aspect of this plan until shared understanding. Walk each branch of the design tree, resolving dependencies one-by-one.

Ask **one question at a time**. Provide your recommended answer with each question.

If a question can be answered by exploring the codebase, explore the codebase instead of asking.
