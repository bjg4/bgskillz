# Evaluation Data Schemas

JSON schemas for all data files produced by the evaluation pipeline. These schemas define the contracts between scripts and agents.

## Test Prompts (input)

File: `prompts.json`

```json
[
  {
    "id": "test-1",
    "prompt": "Help me create a new skill for code review",
    "assertions": [
      "Output includes a SKILL.md template",
      "Description follows the [What] + [When] + [Capabilities] formula",
      "Includes at least one example of good output"
    ]
  }
]
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | Unique test identifier |
| `prompt` | string | Yes | The prompt to send to Claude |
| `assertions` | string[] | No | Pass/fail criteria for grading |

## Evaluation Manifest

File: `evals.json` (generated by `run_eval.py`)

```json
{
  "skill_path": "/path/to/skill",
  "iteration": 1,
  "timestamp": "2026-03-07T10:30:00",
  "test_count": 3,
  "results": [
    {
      "id": "test-1",
      "prompt": "the test prompt",
      "assertions": ["assertion 1", "assertion 2"],
      "with_skill": {
        "output_path": "eval-test-1/with_skill/outputs/response.md",
        "elapsed_seconds": 12.5,
        "success": true
      },
      "without_skill": {
        "output_path": "eval-test-1/without_skill/outputs/response.md",
        "elapsed_seconds": 8.3,
        "success": true
      }
    }
  ]
}
```

## Grading Results

File: `grading.json` (generated by grader agent)

```json
{
  "test_prompt": "the original prompt",
  "claims_extracted": ["claim 1", "claim 2"],
  "grades": [
    {
      "assertion": "the assertion text",
      "grade": "PASS",
      "evidence": "specific evidence from the output",
      "justification": "one sentence explanation"
    }
  ],
  "meta_evaluation": {
    "trivially_satisfied": [],
    "missing_coverage": ["suggested new assertion"],
    "overly_strict": [],
    "ambiguous": []
  },
  "overall_score": 0.85,
  "summary": "Overall assessment paragraph"
}
```

| Grade | Value | Description |
|-------|-------|-------------|
| PASS | 1.0 | Assertion clearly satisfied |
| PARTIAL | 0.5 | Partially satisfied or satisfied in spirit |
| FAIL | 0.0 | Not satisfied |

## Comparison Results

File: `comparison.json` (generated by comparator agent)

```json
{
  "test_prompt": "the original prompt",
  "rubric_source": "generated",
  "dimensions": [
    {
      "name": "Correctness",
      "category": "content",
      "score_a": 4,
      "score_b": 3,
      "winner": "A",
      "justification": "Output A correctly handles edge case X"
    }
  ],
  "total_score_a": 32,
  "total_score_b": 28,
  "overall_winner": "A",
  "key_differentiators": ["differentiator 1"],
  "summary": "Overall comparison paragraph"
}
```

Dimension scores use a 1-5 scale. Categories are `content` or `structure`.

## Analysis Results

File: `analysis.json` (generated by analyzer agent)

```json
{
  "skill_name": "my-skill",
  "patterns": [
    {
      "type": "consistent_win",
      "dimension": "Correctness",
      "description": "Skill consistently produces more accurate code",
      "test_cases": ["test-1", "test-2"],
      "evidence": "specific data points"
    }
  ],
  "suggestions": [
    {
      "priority": "P1",
      "action": "modify",
      "instruction": "the specific instruction to change",
      "rationale": "why this change helps",
      "expected_impact": "what should improve",
      "risk": "potential downsides",
      "overfitting_risk": "low"
    }
  ],
  "overall_assessment": "Summary paragraph",
  "iteration_recommendation": "Advice for next iteration"
}
```

Pattern types: `consistent_win`, `consistent_loss`, `high_variance`, `hidden_by_aggregate`

Priority levels: `P0` (critical), `P1` (important), `P2` (nice to have)

## Timing Data

File: `timing.json` (per eval run)

```json
{
  "elapsed_seconds": 12.5,
  "success": true
}
```

## Benchmark Aggregate

File: `benchmark.json` (aggregated across all test cases)

```json
{
  "iteration": 1,
  "timestamp": "2026-03-07T10:30:00",
  "test_count": 3,
  "with_skill": {
    "mean_score": 0.82,
    "stddev": 0.12,
    "mean_elapsed_seconds": 15.2
  },
  "without_skill": {
    "mean_score": 0.65,
    "stddev": 0.18,
    "mean_elapsed_seconds": 10.1
  },
  "delta": {
    "score_improvement": 0.17,
    "time_overhead_seconds": 5.1
  }
}
```

## Trigger Evaluation Queries

File: `trigger-queries.json` (input for `improve_description.py`)

```json
[
  {
    "id": "q-1",
    "query": "Help me create a new skill",
    "should_trigger": true,
    "category": "exact"
  },
  {
    "id": "q-2",
    "query": "Write a Python script to parse CSV",
    "should_trigger": false,
    "category": "adjacent"
  }
]
```

Categories: `exact` (uses description words), `paraphrase` (same intent, different words), `implicit` (implies skill without naming it), `context-embedded` (buried in longer message), `adjacent` (similar domain, wrong intent), `unrelated` (completely different)

## Trigger Evaluation Results

File: `trigger-eval.json` (output from `improve_description.py`)

```json
{
  "analysis": {
    "skill_name": "my-skill",
    "description": "the current description",
    "total_queries": 20,
    "correct": 18,
    "accuracy": 0.9,
    "false_negatives": 1,
    "false_positives": 1,
    "suggestions": [
      {
        "type": "undertriggering",
        "severity": "medium",
        "description": "Skill failed to trigger on 1 query",
        "fix": "Add more trigger phrases"
      }
    ]
  },
  "results": [],
  "queries": []
}
```

## Workspace Directory Structure

```
my-skill-workspace/
├── iteration-1/
│   ├── evals.json                    # Evaluation manifest
│   ├── benchmark.json                # Aggregate scores
│   ├── eval-test-1/
│   │   ├── with_skill/
│   │   │   ├── outputs/
│   │   │   │   └── response.md       # Claude's response with skill
│   │   │   └── timing.json
│   │   ├── without_skill/
│   │   │   ├── outputs/
│   │   │   │   └── response.md       # Claude's baseline response
│   │   │   └── timing.json
│   │   ├── grading.json              # Grader agent results
│   │   └── comparison.json           # Comparator agent results
│   └── analysis.json                 # Analyzer agent results
├── iteration-2/
│   └── ...
└── feedback.json                     # User feedback across iterations
```
